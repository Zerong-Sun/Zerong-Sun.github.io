# Archived root site (v1)

Dark-theme **Zerong' Notes** site preserved for reference. Previously deployed at `https://zerong-sun.github.io`.

- **Live archive:** `/archive/` on the current homepage
- **Dev:** `npm run archive:dev` from repo root
- **Build:** `npm run archive:build` (outputs to `dist/` with `base: /archive/`)

Content and assets remain the source of truth for `/assets/` images used by colorblog notes.
